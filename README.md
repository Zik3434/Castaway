# Castaway

Pixel-art fishing game prototype. Open `index.html` in a browser.

- Line 1 is your rod. Cast, tap **Reel in!** when it hits, then hold to lift the net and keep the fish inside.
- Line 2 is a set line. Bait it, leave it, come back. It keeps ticking while the game is closed.
- Fish up six pieces of driftwood on Wreck Shoal to build a raft, then sail to Gull Harbor and sell the haul.

`CLAUDE.md` holds the design decisions, the prototype's structure and the roadmap. Start there.
